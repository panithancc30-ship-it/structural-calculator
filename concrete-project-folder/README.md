# rc-beam-wsd — โปรแกรมออกแบบคานคอนกรีตเสริมเหล็ก (WSD)

เว็บแอปออกแบบคาน คสล. หน้าตัดสี่เหล็กผืนผ้าด้วยวิธีหน่วยแรงใช้งาน (Working Stress Design)
ตาม **ACI 318 Alternate Design Method** — กรอกแรงภายใน M, V, T โดยตรง แล้วได้รูปหน้าตัดแบบก่อสร้าง
**SECTION A-A (กลางคาน, M+)** และ **SECTION B-B (ใกล้เสา, M−)** ที่คลิกแก้เหล็กทีละเส้นได้ และพิมพ์เป็น A4 หน้าเดียว

## วิธีใช้

1. กรอกขนาดคาน (b, h, L, covering), วัสดุ (f′c, fy เหล็กยืน, fy เหล็กปลอก), แรงภายใน M, V, T และขนาดเหล็ก
2. โปรแกรมออกแบบเหล็กบน-ล่างของทั้งสองหน้าตัดทันที
   - A-A: M+ → เหล็กล่างรับแรงดึง
   - B-B: M− → เหล็กบนรับแรงดึง
3. **แก้รูปเอง**: คลิกเหล็กเส้นใดก็ได้ → เปลี่ยนขนาด (เส้นเดียวหรือทั้งชั้น) / เพิ่มเส้น / เพิ่มชั้น / ลบ;
   คลิกปลอก → เลือก 1 ปลอก หรือ 2 ปลอก ขนาด และระยะ — ตารางตรวจสอบอัปเดตทันที
4. **ตัวอย่าง A4** ดูใบรายการคำนวณ แล้วกด **พิมพ์ / PDF (A4)**
   (ตั้งค่าเครื่องพิมพ์: A4 แนวตั้ง, ขอบกระดาษค่าเริ่มต้น, ไม่ต้องย่อ/ขยาย)
5. **บันทึกไฟล์ / เปิดไฟล์** เก็บโครงการเป็น `.json` — ข้อมูลล่าสุดถูกจำไว้ในเบราว์เซอร์อัตโนมัติด้วย

## สมมติฐานการคำนวณ (หน่วย kg, cm, ksc)

ค่าคงที่ทั้งหมดของมาตรฐานอยู่ที่ [`src/domain/codes/aci318Wsd.ts`](src/domain/codes/aci318Wsd.ts)

**หน่วยแรงยอมให้**: Ec = 15,100√f′c, n = Es/Ec (ปัดเศษ), fc = 0.45f′c, fs = 0.5fy ≤ 1,700, fv = 0.5fy(ปลอก) ≤ 1,700

**ดัด**: k = 1/(1 + fs/(n·fc)), j = 1 − k/3, R = ½·fc·k·j, Mc = R·b·d²
- M ≤ Mc → As = M/(fs·j·d)
- M > Mc → As = Mc/(fs·j·d) + (M−Mc)/(fs(d−d′)), A′s = (M−Mc)/(fs′(d−d′)), fs′ = 2fs(k−d′/d)/(1−k) ≤ fs
- As,min = 14·b·d/fy; B-B เหล็กล่างต่อเนื่อง ≥ ¼ (ช่วงเดียว ⅓) ของเหล็กล่าง A-A
- d คำนวณจาก centroid ของเหล็กที่วางจริง แล้ววนซ้ำจนจำนวนเหล็กลู่เข้า
- ตรวจหน้าตัดจริงด้วย transformed section (เหล็กรับอัดใช้ 2n) → fc, fs, fs′

**เฉือน + บิด** (ใช้ V, T เดียวกันทั้งสองหน้าตัด — ปลอดภัยไว้ก่อน แก้ระยะปลอกกลางคานเองได้)
- v = V/(b·d), vt = 3T/Σx²y — ละเลยแรงบิดเมื่อ vt ≤ 0.22√f′c
- vc = 0.29√f′c/√(1+(vt/1.2v)²), vtc = 0.35√f′c/√(1+(1.2v/vt)²)
- v − vc ≤ 1.16√f′c, vt ≤ 5·vtc (ไม่ผ่าน → ขยายหน้าตัด)
- Av/s = (v−vc)·b/fv, At/s = (vt−vtc)·Σx²y/(3·αt·x1·y1·fv), αt = 0.66 + 0.33y1/x1 ≤ 1.5
- s max = d/2 (d/4 เมื่อ v−vc > 0.58√f′c), มีแรงบิด ≤ (x1+y1)/4 ≤ 30 ซม., Av + 2At ≥ 3.5·b·s/fy
- Al = max(2At(x1+y1)/s, Al,min) — h < 60 ซม. แบ่งครึ่งบน/ล่าง, h ≥ 60 ซม. แบ่ง ⅓ บน/ล่าง/เหล็กข้าง

**เหล็กปลอก 1 ปลอก / 2 ปลอก**
- 1 ปลอก (2 ขา): 2Ab/s ≥ Av/s + 2At/s
- 2 ปลอก = ปลอกนอก + ปลอกในคร่อมเหล็กกลาง ขนาดเดียวกัน ระยะเดียวกัน ผูกตำแหน่งเดียวกัน (4 ขา):
  4Ab/s ≥ Av/s + 4At/s (แรงบิดใช้ได้เฉพาะปลอกนอก) และเหล็กชั้นแรกบน/ล่าง ≥ 4 เส้น เป็นเหล็กมุมปลอกใน
- โหมดอัตโนมัติ: ใช้ 1 ปลอกก่อน ถ้าระยะ < ค่าต่ำสุดที่ตั้งไว้ (เริ่มต้น 10 ซม.) จึงใช้ 2 ปลอก;
  ถ้ายังไม่พอ แจ้งเตือนพร้อมแนะนำขนาดปลอกที่ใหญ่ขึ้น
- ระยะปลอกปัดลงทีละ 2.5 ซม.

**การจัดเหล็ก**: ระยะช่องว่าง ≥ max(db, 2.5 ซม.), ระหว่างชั้น ≥ 2.5 ซม., ไม่พอ → แตกชั้น (สูงสุด 3 ชั้น)

> ⚠️ เวอร์ชันทดสอบ — ผลคำนวณต้องตรวจสอบโดยวิศวกรผู้มีใบอนุญาตก่อนใช้งานจริง

## ฐานรากแผ่ (แท็บ "ออกแบบฐานราก")

กรอกขนาดเสา แรงที่โคนเสา (P, Mx, My) ค่า qa ของดิน และเลือกตำแหน่งเสา:
**ศูนย์กลาง**, **เยื้องศูนย์** (กำหนด ex, ey), **ตีนเป็ดชิดขอบ** (ซ้าย/ขวา/ล่าง/บน) หรือ **ตีนเป็ดชิดมุม** —
โปรแกรมหาขนาด B × L × t อัตโนมัติ (หรือกำหนดเองเพื่อตรวจสอบ) จัดเหล็กสองทิศ วาดแปลน + รูปตัด X-X, Y-Y
คลิกเหล็กบนแปลนเพื่อแก้ขนาด/จำนวน และพิมพ์ใบรายการคำนวณ A4 ได้ ปุ่ม "นำขนาดเสาและแรงจากโมดูลเสา" ดึงข้อมูลจากแท็บเสา

ค่าคงที่อยู่ที่ `ACI318_WSD_FOOTING` ใน [`src/domain/codes/aci318Wsd.ts`](src/domain/codes/aci318Wsd.ts)

**แรงดันดิน** (ฐานรากแข็ง ดินไม่รับแรงดึง, ดินรับโมเมนต์จากการเยื้องศูนย์ทั้งหมด ไม่มีคานยึด)
- N = P + W, W = B·L·(2.4t + γs(Df − t)); ex = (P·xc + My)/N, ey = (P·yc + Mx)/N — My, Mx บวกทำให้ดินด้าน +x, +y รับแรงมากขึ้น
- ใน kern: q = N/A·(1 ± 6ex/B ± 6ey/L); นอก kern: หาระนาบแรงดันที่สมดุลกับ N, N·ex, N·ey (Newton, อินทิเกรตรูปหลายเหลี่ยมแบบแม่นตรง)
- ตรวจ qmax ≤ qa, แรงลัพธ์อยู่ในฐาน, พื้นที่ดินรับแรงดัน ≥ 50% (ต่ำกว่านั้นเตือน)

**โครงสร้าง** ใช้แรงดันสุทธิ q − w (หักน้ำหนักฐานรากและดินถม)
- ดัดที่ผิวเสา: M ≤ R·b·d², As = M/(fs·j·d) ≥ 0.0020bt (fy < 4,000) หรือ 0.0018·4,000/fy·bt ≥ 0.0014bt;
  ฐานสี่เหลี่ยมผืนผ้า เหล็กทิศสั้นในแถบกลางกว้างเท่าด้านสั้น ≥ 2/(β+1)·As; ผิวบนรับแรงดึง (โมเมนต์ลบ) เตือนเมื่อ 6M/bt² > 0.42√f′c
- เฉือนแบบคานที่ระยะ d: v ≤ 0.29√f′c
- เฉือนทะลุ ห่างผิวเสา d/2 (ด้านที่เลยขอบฐานถูกตัด → เสาขอบ 3 ด้าน, เสามุม 2 ด้าน):
  v = V/(b0·d) + γv·M·c/J ≤ √f′c·min(0.53, 0.265(1 + 2/βc), 0.265(αs·d/b0 + 2)), αs = 40/30/20
- ระยะฝังจากผิวเสาด้านโมเมนต์สูงสุด: ld = 0.06Ab·fy/√f′c ≥ 0.0057db·fy, ไม่พอใช้ขอ 90° ldh = 318db/√f′c·fy/4,200 ≥ 8db
  (ลดตาม As ต้องการ/As ที่ใส่; ส่วนยื่นไม่เกิน d ไม่ตรวจ)
- ระยะเรียง ≤ min(3t, 45 ซม.), ช่องว่าง ≥ max(db, 2.5 ซม.), d ≥ 15 ซม., แรงแบกทานใต้เสา P/A1 ≤ 0.3f′c·√(A2/A1) (เกิน → เตือนให้ใส่เหล็กเดือย)

**ขนาดอัตโนมัติ**: ค้นหาแปลนพื้นที่น้อยสุด (ด้านยาว/ด้านสั้น ≤ 2, ปัดทีละ 5 ซม.) ที่ผ่านแรงดันดิน เลือกรูปที่ใกล้จัตุรัสที่สุด
แล้วหาความหนาน้อยสุดที่ดัด เฉือนแบบคาน และเฉือนทะลุผ่าน วนซ้ำจนขนาดคงที่

## ฐานรากเสาเข็ม (แท็บ "ฐานรากเสาเข็ม")

กรอกขนาดเสา ระยะเยื้องศูนย์ของเสา (ex, ey จากศูนย์ถ่วงกลุ่มเข็ม) เสาเข็ม (สี่เหลี่ยม/กลม, D, Pa, Ta, ระยะห่าง s, ระยะขอบ) และแรงที่โคนเสา
โปรแกรมเลือกจำนวนเข็ม 1–9 ต้น (รูปแบบมาตรฐาน หมุน 90° ได้) และความหนาอัตโนมัติ หรือกำหนดเอง
ตาราง **เสาเข็ม** ให้กรอกระยะเยื้องของเข็มแต่ละต้นหลังตอกจริง (dx, dy) เพื่อตรวจสอบฐานรากเข็มเยื้องศูนย์
ความยาวเสาเข็มแสดงเป็น **L — ขึ้นอยู่กับผลทดสอบดิน** (โปรแกรมไม่คำนวณความยาวเข็ม)

ค่าคงที่อยู่ที่ `ACI318_WSD_PILECAP` ใน [`src/domain/codes/aci318Wsd.ts`](src/domain/codes/aci318Wsd.ts)

**แรงในเสาเข็ม** (ฐานรากแข็ง ไม่มีคานยึด)
- ใช้ตำแหน่งเข็มจริง: R = N/n + a·x′ + b·y′, [Σx′² Σx′y′; Σx′y′ Σy′²]·[a; b] = [My; Mx] รอบศูนย์ถ่วงกลุ่มเข็มจริง (รองรับกลุ่มเข็มไม่สมมาตร)
- My, Mx รวม = M + P·(ศูนย์เสา − ศูนย์ถ่วงกลุ่มเข็ม) (+ W ที่ศูนย์ฐานราก) — เข็มต้นเดียว/แถวเดียว รับโมเมนต์ตั้งฉากแถวไม่ได้ → ไม่ผ่าน (ต้องมีคานยึด)
- ตรวจกำลังเข็มด้วย N = P + W: Rmax ≤ Pa, Rmin ≥ −Ta; ระยะห่างเข็มจริง ≥ 3D และผิวเข็มถึงขอบ ≥ 15 ซม. (ต่ำกว่านั้นเตือน)

**โครงสร้าง** ใช้แรงเข็มจาก P, M เท่านั้น (น้ำหนักฐานรากถ่ายลงเข็มโดยตรง)
- ดัดที่ผิวเสา M = ΣR·(ระยะศูนย์เข็มถึงผิวเสา), As เหมือนฐานรากแผ่; เข็มรับแรงถอน → เตือนให้เสริมเหล็กบน
- เฉือนแบบคานที่ระยะ d และเฉือนทะลุรอบเสาที่ d/2 (รวม γv·M·c/J): เข็มคร่อมหน้าตัดวิกฤตคิดแรงตามสัดส่วน ±D/2 (ACI 15.5.4)
- เฉือนทะลุรอบเข็มแต่ละต้น (เข็มมุม/ขอบหน้าตัดถูกตัดด้วยขอบฐาน) เมื่อหน้าตัดวิกฤตไม่ซ้อนกับของเสา
- d ≥ 30 ซม. (15.7), ระยะฝังเหล็ก, ระยะเรียง, แรงแบกทานใต้เสา เหมือนฐานรากแผ่

**ขนาดอัตโนมัติ**: แปลน = กรอบเข็ม + ระยะขอบ (ขยายให้คลุมเสาที่เยื้อง) ปัดทีละ 5 ซม.; จำนวนเข็มน้อยสุดที่รับแรงได้ ↔ ความหนาน้อยสุดที่ผ่าน วนจนคงที่
