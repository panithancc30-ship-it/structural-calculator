# โปรแกรมคำนวณออกแบบโครงสร้าง — รายการคำนวณเพื่อขออนุญาตก่อสร้าง

เว็บแอปสำหรับวิศวกรโยธาไทย ครอบคลุมทั้ง **โครงสร้างเหล็กรูปพรรณ** (วิธีหน่วยแรงใช้งาน ASD)
และ **คอนกรีตเสริมเหล็ก** (วิธีหน่วยแรงใช้งาน WSD ตามมาตรฐาน วสท.)
รายการคำนวณทั้งสองวัสดุอยู่ในโครงการเดียวกัน และพิมพ์ออกมาเป็นรูปเล่มเดียว
(หน้าปก + สารบัญ + รายการคำนวณพร้อมรูปตัด) เพื่อยื่นประกอบการขออนุญาตก่อสร้าง

## วิธีเริ่มใช้งาน

**บนเครื่อง Windows:** ดับเบิลคลิก `เปิดโปรแกรม.bat` (ติดตั้ง [Node.js](https://nodejs.org) รุ่น LTS ไว้ก่อนครั้งเดียว)
ครั้งแรกจะดาวน์โหลดส่วนประกอบให้เอง แล้วเปิดเบราว์เซอร์ที่ http://localhost:5173
ระหว่างใช้งานให้เปิดหน้าต่างสีดำค้างไว้ ปิดหน้าต่างนั้นเมื่อเลิกใช้

หรือสั่งเองจาก terminal:

```bash
npm run dev -- --port 5173 --strictPort
```

ใช้ที่อยู่ http://localhost:5173 และเบราว์เซอร์ตัวเดิมทุกครั้ง — งานที่บันทึกผูกกับที่อยู่และเบราว์เซอร์
ถ้าเปิดด้วยพอร์ตอื่นหรือเบราว์เซอร์อื่น จะเห็นเป็นโครงการว่าง (ข้อมูลไม่ได้หาย ย้ายด้วยไฟล์สำรอง JSON ได้)

## แนวคิดการใช้งาน

ทั้งสองวัสดุรับ **แรงภายในที่ผู้ใช้คำนวณมาแล้ว** (M, V, T, P) เป็นข้อมูลนำเข้า
แล้วแสดงผลผ่าน/ไม่ผ่านทีละเงื่อนไขทันทีที่แก้ค่า แต่บทบาทของโปรแกรมต่างกัน:

| | โครงสร้างเหล็ก | คอนกรีตเสริมเหล็ก |
| --- | --- | --- |
| บทบาท | **ตรวจสอบ** หน้าตัดที่ผู้ใช้เลือก | **ออกแบบให้** แล้วผู้ใช้แก้ได้ |
| ผู้ใช้กำหนด | หน้าตัด เกรดเหล็ก มุมเอียง การค้ำยัน | ขนาดหน้าตัด วัสดุ แรงภายใน |
| โปรแกรมจัดให้ | (มีปุ่มแนะนำหน้าตัดที่เบาที่สุดที่ผ่าน) | จำนวนและขนาดเหล็กเสริม ปลอก ขนาดฐานราก จำนวนเสาเข็ม |
| แก้ด้วยมือ | เปลี่ยนหน้าตัดในฟอร์ม | **คลิกที่เหล็กในรูปหน้าตัด** เพื่อเปลี่ยนขนาด/เพิ่ม/ลบ |

เมื่อแก้เหล็กเอง รายการนั้นจะติดป้าย “แก้ไขเอง” — เปลี่ยนข้อมูลนำเข้าแล้วโปรแกรมจะตรวจสอบใหม่
แต่ไม่จัดเหล็กใหม่ให้ จนกว่าจะกด “ออกแบบอัตโนมัติใหม่”

## ขั้นตอนการทำงาน

1. **แท็บ "ข้อมูลโครงการ"** — กรอกชื่อโครงการ เจ้าของ ผู้คำนวณ เลขใบอนุญาต (ใช้ขึ้นหน้าปก)
2. **แท็บ "รายการคำนวณ"** — ป้อนค่า ดูผลสด แล้วกด "บันทึกเข้ารูปเล่ม" (1 รายการ = 1 ตำแหน่งวิกฤต
   เช่น แปที่ต้องตรวจทั้งแรงกดและแรงลมยก ให้สร้าง 2 รายการแยกกัน)
3. **แท็บ "พิมพ์รูปเล่ม"** — กด "พิมพ์ / บันทึกเป็น PDF" แล้วเลือกปลายทางเป็น "Save as PDF"
   ขนาดกระดาษ A4 และเปิด "กราฟิกพื้นหลัง" เพื่อให้ตารางแสดงครบ

**แท็บ "Design Criteria"** แสดงเกณฑ์การออกแบบตามกฎกระทรวงและมาตรฐาน วสท. (วัสดุ น้ำหนักบรรทุก ดิน เสาเข็ม
ระยะหุ้มกันไฟ) เป็นข้อมูลอ้างอิงเท่านั้น **ไม่ได้ผูกกับสูตรคำนวณ** — ค่าอ่านจาก
[`src/features/design-criteria/designCriteria.json`](src/features/design-criteria/designCriteria.json)
แก้ไฟล์นี้ได้โดยไม่กระทบผลของรายการคำนวณ
ในรูปเล่มจะพิมพ์เป็น 3 หน้าต่อจากสารบัญ (มีรายการในสารบัญ) รายการคำนวณจึงเริ่มหน้า 6
การแบ่งหมวดลงแต่ละหน้ากำหนดที่ `CRITERIA_PRINT_PAGES` ใน `criteriaModel.ts`

## การเก็บข้อมูล

ข้อมูลเก็บในเบราว์เซอร์ของเครื่องนี้ (IndexedDB) ไม่มีการส่งขึ้นเซิร์ฟเวอร์
ข้อมูลโครงการบันทึกทันทีที่แก้ ส่วนรายการคำนวณบันทึกเมื่อกด "บันทึกเข้ารูปเล่ม" เท่านั้น
(ค่าที่กรอกค้างไว้แต่ยังไม่กด จะหายเมื่อปิดหรือรีเฟรชหน้า)
**ควรกด "สำรองข้อมูลเป็นไฟล์ JSON" เป็นระยะ** เพราะหากล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหายไป

## ขอบเขตปัจจุบัน

หน่วยเดียวกันทั้งโปรแกรม: ksc / กก. / ซม.

**โครงสร้างเหล็กรูปพรรณ** (AISC ASD 9th / วสท.)
- คานเหล็ก / จันทัน / แป
- เสาเหล็ก
- เสาเหล็กหุ้มคอนกรีต — แรงอัดตามแนวแกนตามมาตรฐาน วสท. แนะนำหน้าตัดเหล็กที่เบาที่สุดให้

**คอนกรีตเสริมเหล็ก** (มาตรฐาน วสท. วิธีหน่วยแรงใช้งาน — ดูรายการสูตรด้านล่าง)
- คาน คสล. — ตรวจสองหน้าตัด A-A (กลางคาน, M+) และ B-B (ใกล้เสา, M−) รวมแรงบิด
- คานรับพื้นยื่น — กรอกความยาวพื้นยื่นและน้ำหนักใช้งาน โปรแกรมคิดน้ำหนักลงคาน M, V และแรงบิดให้ แล้วออกแบบเหล็กตาม วสท.
- เสา คสล. — ปลอกเดี่ยว / ปลอกเกลียว พร้อมแผนภาพ P–M และผลความชะลูด
- ฐานรากแผ่ — หาขนาดให้อัตโนมัติ รองรับเสาศูนย์กลาง เยื้องศูนย์ ตีนเป็ดชิดขอบ/ชิดมุม
- ฐานรากเสาเข็ม — จัดกลุ่มเข็มอัตโนมัติ คำนวณแรงในเข็มทีละต้น รวมระยะเยื้องหลังตอก
- พื้นหล่อในที่ — ทางเดียว สองทาง พื้นยื่น และพื้นวางบนดิน หาความหนาและจัดเหล็กให้จากน้ำหนักบรรทุก
- บันไดท้องเรียบ — พาดตามยาวระหว่างคาน คิดน้ำหนักขั้นบันไดและชานพักให้ เขียนรูปตัดพร้อมเหล็กขั้นบันได

ยังไม่รวม: จุดต่อเหล็ก (สลักเกลียว รอยเชื่อม), แผ่นเหล็กใต้เสา, กำแพงกันดิน, สรุปปริมาณวัสดุ

## โมดูลโครงสร้างเหล็ก

### คาน จันทัน และแป คือชิ้นส่วนชนิดเดียวกัน

ต่างกันแค่มุมสองตัว ซึ่งปรับได้อิสระ (มีปุ่มตั้งค่าสำเร็จรูปให้)

| มุม | ความหมาย | ผลต่อการคำนวณ |
|---|---|---|
| **θm** มุมเอียงของชิ้นส่วน | แกนชิ้นส่วนเทียบแนวราบ | แปลงช่วงราบเป็นช่วงตามความลาด (L/cos θm) และใช้ร่วมกับแรงตามแกน P |
| **θs** มุมเอียงของหน้าตัด | หน้าตัดหมุนรอบแกนชิ้นส่วน | แตกโมเมนต์จากแรงดิ่ง: Mx = M·cos θs, My = M·sin θs → ตรวจการดัดสองแกน |

- **คานราบ** θm = 0, θs = 0
- **แป** (วางขวางแนวลาด หน้าตัดเอียงตามหลังคา) θm = 0, θs = ความชันหลังคา — เลือกเหล็กยึดทางข้าง (sag rod) เพื่อลด My ได้
- **แปหมวก** (รับกระเบื้อง บนจันทันห่างไม่เกิน 1 ม.) มีปุ่มตั้งค่าสำเร็จรูป — หน้าตัดกว้างกว่าสูง (Iy ≥ Ix) จึงไม่เกิดการโก่งเดาะด้านข้าง
- **จันทัน** (วางตามแนวลาด) θm = ความชันหลังคา, θs = 0 — จันทันที่ "เอวตั้งดิ่ง" กับ "เอวตั้งฉากหลังคา" คือการวางแบบเดียวกัน จึงไม่เกิดการดัดแกนอ่อน

ผู้ใช้ป้อน M, V (และ P ถ้ามี) เอง การโก่งตัวย้อนคำนวณจาก M ตามรูปแบบแรงที่เลือก และพิมพ์สมมติฐานนั้นลงในรายการคำนวณ

### คุณสมบัติหน้าตัดคำนวณจากรูปทรง ไม่ได้ลอกจากตารางผู้ผลิต

ตารางใน `src/engine/steel/sectionTable.ts` เก็บเฉพาะมิติ (เช่น H200×100×5.5×8 รัศมีมุม 11 มม.)
แล้วคำนวณ A, Ix, Iy, Sx, Sy, r ฯลฯ ใน `geometry.ts` — ชุดทดสอบเทียบกับตาราง JIS G3192 / มอก. ภายใน 2%
รายการคำนวณพิมพ์กำกับที่มาของค่าเสมอ มีหมวด: เหล็ก H หน้ากว้าง/หน้าแคบ, I, รางน้ำ, ตัวซี มอก. 1228,
ฉากขาเท่า/ไม่เท่า, กล่องจัตุรัส/ผืนผ้า, ท่อกลม, ตัวซีบาง G550, แปหมวก (Top Hat) และหน้าตัดที่ป้อนคุณสมบัติเอง

หน้าตัดประกอบ: 2 รางน้ำหลังชนหลัง / ประกบเป็นกล่อง, 2 เหล็กฉาก, 2 กล่อง/ท่อวางคู่ (ตรวจระยะห่างจุดยึดตาม AISC E4)

ปุ่ม **แนะนำหน้าตัดประหยัดสุด** ไล่ตรวจทุกหน้าตัดในหมวดที่เลือกด้วยเอนจินเดียวกับที่ใช้ตรวจจริง แล้วเรียงจากเบาที่สุด

### ข้อควรรู้

- **รางน้ำและเหล็ก I รีดร้อนมีปีกสอบ** แต่โมเดลใช้ปีกขนาน → Iy, Sy สูงกว่าตารางราว 10–15%
  โปรแกรมจะเตือนทุกครั้ง หากมีการดัดรอบแกนอ่อนต้องเทียบกับตารางผู้ผลิต
- **เหล็กขึ้นรูปเย็น (มอก. 1228, G550)** ใช้หน้าตัดประสิทธิผลตาม AISI B2 และกำลังอัดตาม AISI C4
  ส่วนการโก่งเดาะด้านข้างใช้ AISC F1-8 (ปลอดภัยกว่า AISI C3.1.2) — แปที่ยึดแผ่นหลังคากับปีกบนด้วยสกรู
  ใส่ Lb เป็นระยะห่างสกรูได้ (กรณีแรงกดลง)
- **เหล็กสำเร็จรูป SCG / CPAC** มี 2 หมวด: ตัวซีบาง G550 (โครงหลังคาสำเร็จรูป) และ **แปหมวก** (แปรับกระเบื้อง
  เช่น "แป ซีแพค" หนา 0.55 / 0.70 มม.) ผู้ขายระบุเพียงกว้าง 65 สูง 30 มม. และน้ำหนัก — ความกว้างสัน ระยะเอว
  และขอบพับเป็นค่าสมมติ **แก้มิติได้ในฟอร์ม** ควรวัดจากของจริง และใช้ความหนาเหล็กไม่รวมสารเคลือบ
- แปหมวกและหน้าตัดไม่สมมาตรรอบแกนนอน: ใส่ **M ติดลบ** เพื่อตรวจกรณีแรงลมยก (ปีกรับแรงอัด)
  ยังไม่ได้ตรวจการยุบตัวของเอวที่จุดรองรับ (web crippling) และกำลังสกรูยึด
- **เหล็ก G550 บางกว่า 0.9 มม.** ใช้กำลังครากออกแบบ 4,125 ksc (75% ตาม AISI S100 A2.3.2 / AS/NZS 4600)
- **พิมพ์ 1 หน้าต่อ 1 รายการ** — ถ้ารายการใดยาวเกิน (เช่น หมายเหตุยาว) โปรแกรมจะย่อเฉพาะรายการนั้นตอนพิมพ์
  ไม่ต่ำกว่า 85% และแจ้งไว้เหนือรูปเล่มในแท็บ "พิมพ์รูปเล่ม"

### เสาเหล็กหุ้มคอนกรีต

เหล็กรูปพรรณ (H / I) หุ้มด้วยคอนกรีตเสริมลวดตาข่าย รับ **แรงอัดตามแนวแกนเท่านั้น**
ตามมาตรฐาน วสท. (ที่มา ACI 318-63 ข้อ 1406) — สูตรและเกณฑ์อยู่ที่
[`src/engine/steel/encasedColumn.ts`](src/engine/steel/encasedColumn.ts)

| เรื่อง | สูตร / เกณฑ์ |
| --- | --- |
| กำลังรับน้ำหนัก | P = Ar·fr′·(1 + Ag/(100·Ar)), Ag = b × t (หน้าตัดคอนกรีตทั้งหมด) |
| หน่วยแรงยอมให้ของเหล็ก | fr′ = 1,195 − 0.0342(h/Ks)², ใช้ได้เมื่อ h/Ks ≤ 120, Ks = รัศมีไจเรชันแกนที่น้อยสุด |
| คอนกรีตหุ้ม | หนา ≥ 6 ซม. ทุกด้าน, ด้านแคบของเสา ≥ 20 ซม., f′c ≥ 200 ksc ⚠ |
| ลวดตาข่าย | เบอร์ 10 AS&W (Ø 3.4 มม.) ลวดรอบเสา @ ≤ 10 ซม. ลวดตามยาว @ ≤ 20 ซม. ห่างผิว 2.5 ซม. ทาบ ≥ 40d |

- ผู้ใช้กำหนดขนาดเสา ความสูง และแรงอัด — ตัวช่วยแนะนำไล่ตรวจหน้าตัด H / I ทุกขนาดแล้วเรียงจากเบาที่สุด
  (คัดเฉพาะเงื่อนไขที่ขึ้นกับหน้าตัด: h/Ks, กำลัง, ระยะหุ้ม) และมีปุ่มปรับขนาดเสาให้เล็กสุดที่หุ้มเหล็กได้
- h คือความยาวไร้การค้ำยัน เสายื่นหรือโครงที่เซได้ให้ใส่ความยาวประสิทธิผลเอง
- ⚠ f′c ขั้นต่ำ 200 ksc ตามข้อมูลที่ได้รับ แต่ ACI 318-63 ต้นฉบับกำหนด 2,500 psi (≈ 176 ksc)
  และตัวอย่างในตำราใช้ 180 ksc ต้องทานกับฉบับจริง
- ตรวจกับตัวอย่าง 6.4 (เสา 25 × 25 ซม. สูง 3.50 ม. WF125×23.3): fr′ = 761.84 ksc, P = 27,853 กก.
  ตรงกับตำรา — หน้าตัด H125×125 ในตาราง มอก. ของโปรแกรมให้ 27,789 กก. (Ar ต่างจากตารางในตำราเล็กน้อย)
- ไม่ได้ตรวจแป้นรับน้ำหนักพื้น (bracket) และกำลังเหล็กเปล่าช่วงก่อสร้าง — โปรแกรมพิมพ์ Ps = Ar·fr′ ไว้ให้เทียบ

### แก้เหล็กในรูปได้โดยตรง

รูปหน้าตัดในแท็บ “รายการคำนวณ” เป็นแบบก่อสร้างที่คลิกได้ — คลิกเหล็กเส้นใดก็ได้เพื่อเปลี่ยนขนาด
(เส้นเดียวหรือทั้งชั้น) เพิ่มเส้น เพิ่มชั้น หรือลบ; คลิกปลอกเพื่อเลือก 1 หรือ 2 ปลอก ขนาด และระยะเรียง
ตารางตรวจสอบอัปเดตทันที

### ข้อควรรู้

- **คาน คสล.** ใช้ M ค่าเดียวออกแบบทั้ง M+ (A-A) และ M− (B-B) ส่วน V และ T ใช้ตรวจทั้งสองหน้าตัด
  — ปลอดภัยไว้ก่อน ถ้าต้องการระยะปลอกกลางคานที่ห่างกว่า ให้แก้เอง
- **เสา คสล.** ตามมาตรฐาน วสท.: แรงอัดตามแนวแกน P = 0.85Ag(0.25f′c + fs·ρg) (ปลอกเกลียวไม่คูณ 0.85),
  fs = 0.4fy ≤ 2,100 ksc; แรงอัดร่วมดัดใช้ fa/Fa + fb/Fb ≤ 1 เมื่ออัดควบคุม และเส้นตรงจาก Mo ถึงจุดสมดุลเมื่อดึงควบคุม
  เสายาวคูณกำลังยอมให้ด้วย R = 1.32 − 0.006·Lu/r ≤ 1.0 ตามมาตรฐาน วสท. (เสาที่มีคานและพื้นยึดไม่ให้เซ
  R = 1 เมื่อ Lu/r ≤ 53.3 เช่น เสา 20×20 สูงไม่เกิน 3.2 ม.) — ไม่ใช้วิธีขยายโมเมนต์ของ ACI ที่ใช้ 2.5P
  แรงดัดสองแกนตรวจด้วย Mx/Mcx + My/Mcy ≤ 1 ที่แรงอัดเดียวกัน (เทียบเท่า fa/Fa + fbx/Fb + fby/Fb ≤ 1)
- **ฐานรากแผ่** แรงดันดินคิดจากแรงใช้งานแบบฐานรากแข็งและดินไม่รับแรงดึง; qa เทียบกับแรงดันรวม
  น้ำหนักฐานรากและดินถม ส่วนการออกแบบโครงสร้างใช้แรงดันสุทธิ (q − w)
  ฐานรากตีนเป็ดให้ดินรับโมเมนต์จากการเยื้องศูนย์ทั้งหมด (ไม่มีคานยึด) จึงใหญ่กว่าฐานรากเสาศูนย์กลาง
- **ฐานรากเสาเข็ม** แรงในเข็มแปรผันเชิงเส้นรอบศูนย์ถ่วงกลุ่มเข็มจริง กรอกระยะเยื้องของเข็มที่ตอกจริง
  เพื่อตรวจซ้ำได้ ความยาวเข็มขึ้นอยู่กับผลทดสอบดิน โปรแกรมไม่ได้คำนวณให้
- **เหล็กเสริมแบบตะกร้อ** ใช้อัตโนมัติกับฐานรากเข็มต้นเดียว และฐานรากที่หนาตั้งแต่ 0.90 ม.
  เหล็กทั้งสองทิศงอเป็นวงปิดหุ้มผิวล่าง ผิวข้าง และผิวบน เหล็กกันร้าว ρ·b·t แบ่งขาล่างและขาบนขาละครึ่ง
  ระยะเรียงไม่เกิน 20 ซม. (ค่าเขียนแบบ) ขาบนใช้เป็นเหล็กบนเมื่อเข็มรับแรงถอน
  ปิดหรือเปิดเองได้ — คลิกเหล็กในแปลน แล้วกด "ใช้เหล็กตะกร้อ" หรือ "เลิกใช้ตะกร้อ"
- รายการคอนกรีตมีตารางยาวกว่างานเหล็ก หน้ารายงานจึงใช้ตัวอักษรเล็กกว่าเล็กน้อย
  และแปลนกับรูปตัดของฐานรากใช้ **มาตราส่วนเดียวกันทั้งแผ่น**

### พื้นหล่อในที่ — โปรแกรมคำนวณโมเมนต์ให้เอง

ต่างจากโมดูลคาน คสล. ที่ผู้ใช้ป้อน M เอง โมดูลพื้นรับ **น้ำหนักบรรทุก** แล้วหาโมเมนต์ให้:
กรอกความกว้างช่วง สภาพขอบ น้ำหนักวัสดุปูผิว และน้ำหนักจร — น้ำหนักตัวพื้นโปรแกรมคิดจากความหนาที่เลือกให้

| ชนิดพื้น | โมเมนต์ที่ใช้ | ความหนาขั้นต่ำ |
| --- | --- | --- |
| ทางเดียว | แถบเดียวตามช่วงสั้น M = w·L²/ตัวหาร ตามความต่อเนื่องของขอบ | L/20, L/24, L/28 |
| สองทาง | แบ่งน้ำหนักด้วย Rankine–Grashof แล้วออกแบบสองแถบแยกกัน | เส้นรอบรูป/180 |
| พื้นยื่น | M = w·L²/2 เหล็กหลักอยู่ผิวบน | L/10 |
| พื้นวางบนดิน | ไม่ออกแบบรับดัด — กำหนดความหนาและเหล็กกันร้าวตามการใช้งาน | ตามการใช้งาน |

เหล็กพื้นระบุเป็น **ระยะเรียง** ("DB12 @0.25") ไม่ใช่จำนวนเส้น คลิกที่เหล็กหรือป้ายในแปลนเพื่อเปลี่ยนขนาด
และปรับระยะทีละ 2.5 ซม. ได้ เส้นประในแปลนคือเหล็กผิวบน

เลือกได้ทั้ง **เหล็กกลม RB และเหล็กข้ออ้อย DB** ทั้งเหล็กหลักและเหล็กกันร้าว (พื้นบางมักใช้ RB6/RB9)
โปรแกรมเตือนให้เมื่อจับคู่ชนิดเหล็กกับ fy ไม่ตรงตามปกติ เช่น เลือก RB แต่ตั้ง fy สูงกว่า SR24

### ข้อควรรู้ของโมดูลพื้น

- **พื้นสองทางใช้ตารางสัมประสิทธิ์โมเมนต์ วิธีที่ 2 ตามมาตรฐาน วสท.** M = C·w·S² ทั้งสองทิศ (S = ช่วงสั้น)
  เลือกกรณี 1–5 ตามจำนวนขอบไม่ต่อเนื่อง เทียบค่าเชิงเส้นตาม m = S/L และคิดโมเมนต์ของแถบกลางทั้งแผ่น (ปลอดภัยไว้ก่อน)
  น้ำหนักลงคาน: คานด้านสั้น w·S/3, คานด้านยาว w·S/3·(3 − m²)/2
  ตารางอยู่ที่ `method2Coefs` ใน `aci318Wsd.ts` — **พิมพ์จากความรู้ทั่วไป ต้องทานกับตารางในมาตรฐานฉบับจริง**
- **ยังไม่ได้ออกแบบเหล็กกันบิดที่มุมแผ่น** ของพื้นสองทางที่มีขอบไม่ต่อเนื่อง
- **พื้นวางบนดินยังไม่ตรวจน้ำหนักกระทำเป็นจุดหรือล้อรถ** (Westergaard/PCA) ซึ่งต้องใช้ค่า
  modulus of subgrade reaction จากผลทดสอบดิน — โปรแกรมขึ้นคำเตือนไว้ในรายการตรวจสอบและในหมายเหตุของหน้ารายงาน
- **พื้นวางบนดินเสริมตะแกรงชั้นเดียว** ตามงานจริง เพราะระยะหุ้มหล่อติดดิน 7.5 ซม. สองผิวจะไขว้กันในพื้นบาง
- **รูปตัดแสดงเหล็กที่ฝังลงไปในคานรองรับ** และเหล็กผิวบนวาดเฉพาะช่วงใกล้ขอบต่อเนื่องตามที่ตัดเหล็กจริง
  แปลนกับรูปตัดใช้คนละมาตราส่วน (เขียนกำกับไว้ใต้รูปแต่ละรูป) เพราะรูปตัดพื้นเป็นแถบยาวและบาง
- **ควบคุมการโก่งตัวด้วยความหนาขั้นต่ำเท่านั้น** ไม่ได้คำนวณค่าการโก่งตัวจริง
  ผลตรวจจึงเป็น "ควรตรวจสอบ" ไม่ใช่ "ไม่ผ่าน" เมื่อพื้นบางกว่าเกณฑ์
- **ค่าคงที่ของมาตรฐานทั้งหมดอยู่ที่** `ACI318_WSD_SLAB` ใน
  [`src/engine/concrete/codes/aci318Wsd.ts`](structural-app/src/engine/concrete/codes/aci318Wsd.ts)
  ทั้งสัมประสิทธิ์โมเมนต์ 8.3.3 และความหนาขั้นต่ำ Table 9.5(a) — **ต้องทานกับมาตรฐานฉบับพิมพ์ก่อนใช้งานจริง**

### บันไดท้องเรียบ — ออกแบบเป็นพื้นทางเดียวพาดตามยาว

กรอกลูกตั้ง ลูกนอน จำนวนลูกตั้ง ส่วนราบที่ปลายทั้งสอง (วัดจากศูนย์กลางคานรองรับ) และน้ำหนักปูผิวกับน้ำหนักจร
โปรแกรมคิดน้ำหนักตัวเองบนพื้นที่ฉายราบแยกสองช่วง แล้วหาความหนาและจัดเหล็กให้

| ขั้นตอน | สูตร |
| --- | --- |
| น้ำหนักช่วงลาด | 2,400 × (t/cos θ + R/2) + ปูผิว + จร |
| น้ำหนักส่วนราบ | 2,400 × t + ปูผิว + จร |
| M ช่วงยึดหมุน | สถิตศาสตร์ของน้ำหนักแผ่เป็นช่วง (หาจุดที่แรงเฉือนเป็นศูนย์) |
| M ออกแบบ | ใช้สัมประสิทธิ์ของพื้นกับน้ำหนักเทียบเท่า w = 8M/L² — M+ = wL²/8, 14, 16 ตามความต่อเนื่อง |
| เหล็กบนที่ปลาย | ปลายต่อเนื่องใช้ wL²/10 หรือ 11 ส่วนปลายที่หล่อติดคานใช้ wL²/24 (ACI 8.3.3) |

- **รูปตัดเขียนตามแบบก่อสร้าง** — ขั้นบันได คานรองรับ มิติ N@R และ (N−1)@T ระดับ ±0.00 กับปลายบน
  เลือกได้ว่าบันไดขึ้นซ้ายหรือขวา เพื่อเขียนสองช่วงของบันไดหักกลับให้ตรงกับแปลน
- **เหล็กรับแรงดึงที่มุมหักด้านในวางไขว้** แทนการดัดตามมุม: มุมล่าง (ผิวบนเป็นมุมใน) เหล็กบนไขว้
  มุมบน (ผิวล่างเป็นมุมใน) เหล็กล่างไขว้ แต่ละเส้นวิ่งเลยจุดหักไปทาบผิวตรงข้าม 40 ซม. (ค่าเขียนแบบ)
- **เหล็กขั้นบันไดเป็นเหล็กตามแบบ ไม่ได้คำนวณ** เป็นซิกแซก: จากมุมขั้นทะแยงลงไปวางบนเหล็กล่าง แล้วขึ้นไปมุมขั้นถัดไป
  มีเหล็กมุมขนาดเดียวกันทุกจุดหัก ทั้งมุมขั้น (รวมขอบส่วนราบบน) และมุมที่ท้องบันได
- **ความหนาขั้นต่ำใช้ Table 9.5(a) กับช่วงราบ L** ไม่ได้นับความแข็งที่ขั้นบันไดช่วยเพิ่ม จึงมักหนากว่าที่ใช้กันทั่วไป
  ถ้ากำหนดความหนาเองให้บางกว่า ผลจะเป็น "ควรตรวจสอบ"
- **ขนาดขั้นบันไดตรวจตามกฎกระทรวงฉบับที่ 55** (ลูกตั้ง ลูกนอน ความสูงต่อช่วง ความกว้าง) และระยะก้าว 2R + T
  ผลเป็นคำเตือนเท่านั้น — ค่าใน `ACI318_WSD_STAIR` พิมพ์จากความรู้ทั่วไป **ต้องทานกับกฎกระทรวงฉบับปัจจุบัน**

### คานรับพื้นยื่น — กรอกน้ำหนักบรรทุก โปรแกรมคิด M, V, T ให้

ต่างจากโมดูลคาน คสล. ที่ผู้ใช้ป้อน M, V, T เอง โมดูลนี้รับ **ความยาวพื้นยื่นและน้ำหนักใช้งาน**
(พร้อมความหนาพื้น วัสดุปูผิว ผนังที่ปลายพื้นยื่น ผนังบนคาน และน้ำหนักอื่นที่ลงคาน) แล้วคิดแรงภายในให้
จากนั้นออกแบบหน้าตัด A-A และ B-B ด้วยเครื่องมือเดียวกับคาน คสล. — คลิกแก้เหล็กในรูปได้เหมือนกัน

| ขั้นตอน | สูตร |
| --- | --- |
| น้ำหนักบนพื้นยื่น | ws = 2,400·t + ปูผิว + จร (กก./ตร.ม.) |
| น้ำหนักลงคาน | w = ws·Lc + ผนังปลายพื้น + ผนังบนคาน + 2,400·b·h + น้ำหนักอื่น |
| แรงบิดต่อความยาว | t = ws·Lc²/2 + P·Lc (P = ผนังที่ปลายพื้น) |
| โมเมนต์ | ช่วงเดียว M+ = wL²/8 (ไม่มี M−) · ต่อเนื่องปลายเดียว wL²/14, wL²/10 · สองปลาย wL²/16, wL²/11 |
| หน้าตัดวิกฤต | ห่างที่รองรับ d: Vd = V − w·d, Td = t·(L/2 − d) — ปลายคานยึดไม่ให้บิด T = t·L/2 |
| หน่วยแรงบิด | vt = 3.5·T/Σx²y ≤ 1.32√f′c และ v + vt ≤ 1.65√f′c |
| เหล็กรับแรงบิด | vt > 0.29√f′c: ปลอกปิด At/s = T/(2·Ac·fv) ต่อขา, เหล็กยืน Al = T·2(x1 + y1)/(2·Ac·fs) |
| เหล็กรับแรงเฉือน | Av/s = (v − vc)·b/fv, s ≤ d/2 (d/4 เมื่อ v − vc > 0.795√f′c), Av ≥ 0.0015·b·s เสมอ |

สูตรแรงเฉือนและแรงบิดมาจากเอกสาร RC-WSD บทที่ 4 (แรงเฉือน แรงยึดหน่วง และแรงบิด) ค่าคงที่อยู่ที่
`ACI318_WSD_TORSION` และ `ACI318_WSD_LEDGE` ใน `aci318Wsd.ts` ชุดทดสอบ `src/engine/concrete/ledge/ledge.test.ts`
เทียบกับตัวอย่างที่ 1, 2 และ 4 ของเอกสาร (คาน 0.15 × 0.35 ม. ช่วง 4 ม.: w = 556 กก./ม., t = 170 kg·m/m,
M = 1,112 kg·m, Vd = 956 kg, vt = 12.99, v + vt = 15.26 ksc, ปลอก 9 มม. @ 0.125 ม.)

- **ความยาวพื้นยื่น Lc วัดจากศูนย์กลางคาน** ตามตัวอย่างในเอกสาร และคิดน้ำหนักคานเต็มหน้าตัด (ปลอดภัยไว้ก่อน)
- **ผนังที่ปลายพื้นยื่นทำให้คานบิด** ส่วนผนังบนคานและน้ำหนักอื่นลงคานตรง ไม่ทำให้บิด
- **V และ T ที่หน้าตัดวิกฤตใช้ตรวจทั้งสองหน้าตัด** จึงรวม M+ สูงสุดกับแรงบิดสูงสุด (ปลอดภัยไว้ก่อน) เหมือนตัวอย่างในเอกสาร
  ตำแหน่งหน้าตัดวิกฤตใช้ d โดยประมาณ = h − covering − Ø ปลอก − Ø เหล็กยืน/2
- **Σx²y คิดเฉพาะหน้าตัดคานสี่เหลี่ยม** ไม่นับปีกพื้น (ปลอดภัยไว้ก่อน) และไม่ได้จำกัดระยะปลอกตามแรงบิดเพิ่มจาก d/2, d/4
  เพราะเอกสารไม่ได้ระบุ
- **ช่วงเดียวไม่มีโมเมนต์ลบ** เหล็กบนที่ปลายคานจึงมีเฉพาะส่วนที่รับแรงบิด (ไม่ใช้ As,min เมื่อ M = 0)
- **คาน คสล. ทั่วไปยังใช้แรงบิดตาม ACI 318-83** (vt = 3T/Σx²y) — ผลของคานเดียวกันจึงต่างจากโมดูลนี้ได้
- ปลอกในของ 2 ปลอกไม่รับแรงบิด โหมดอัตโนมัติจึงใช้ 2 ปลอกเฉพาะเมื่อได้ระยะห่างขึ้นจริง ถ้าแรงบิดคุมจะคงปลอกเดี่ยว
  และแนะนำขนาดใหญ่ขึ้นแทน

## คำเตือน

โปรแกรมนี้เป็นเครื่องมือช่วยคำนวณ **ผู้ใช้ซึ่งเป็นวิศวกรผู้มีใบอนุญาตต้องตรวจสอบสมมติฐาน
สูตร และผลลัพธ์ทุกครั้งก่อนนำไปใช้งานจริง** ผู้พัฒนาไม่รับผิดชอบต่อความเสียหายที่เกิดจากการใช้งาน

## คำสั่งสำหรับผู้พัฒนา

```bash
npm run dev        # เปิด dev server
npm test           # รันชุดทดสอบ engine คำนวณ (vitest)
npm run typecheck  # ตรวจ TypeScript
npm run lint       # oxlint
npm run build      # build เป็น static site (โฟลเดอร์ dist)
```

สูตรคำนวณทั้งหมดอยู่ใน `src/engine/` (เป็น TypeScript ล้วน ไม่พึ่ง UI) พร้อมชุดทดสอบเทียบการคำนวณมือ

- `src/engine/steel/*.test.ts` — คุณสมบัติหน้าตัดเทียบตาราง JIS/มอก., หน่วยแรงที่ยอมให้ AISC ASD,
  มุมเอียง θm/θs, หน้าตัดประสิทธิผล AISI
- `src/engine/concrete/**/*.test.ts` — หน่วยแรงยอมให้ WSD, การจัดเหล็กดัด, เฉือน+บิด,
  แรงดันดินใต้ฐานราก, เฉือนทะลุ, แรงในเสาเข็ม, การแบ่งน้ำหนักพื้นสองทางและสัมประสิทธิ์โมเมนต์,
  น้ำหนักบันไดบนพื้นที่ฉายราบและสถิตศาสตร์ของน้ำหนักแผ่เป็นช่วง,
  น้ำหนักและแรงบิดของคานรับพื้นยื่นเทียบตัวอย่างในเอกสาร วสท.

ชนิดรายการคำนวณทั้งหมดลงทะเบียนไว้ที่ `src/features/registry.ts` — การเพิ่มโมดูลใหม่
ทำได้โดยเพิ่มรายการในไฟล์นี้ และเพิ่มชื่อชนิดใน `CALC_SHEET_KINDS` (`src/engine/shared/types.ts`)
ไม่ต้องแก้หน้าจอหลักหรือรูปเล่ม

### โมดูลคอนกรีตเชื่อมกับรูปเล่มอย่างไร

โมดูลคอนกรีตเดิมเป็นแอพเดี่ยวที่เก็บสถานะไว้ใน zustand store ก้อนเดียวต่อชนิด
ส่วนรูปเล่มเก็บรายการคำนวณเป็นข้อมูลก้อนหนึ่งต่อหนึ่งรายการ
`src/features/concrete/concreteDraft.ts` ทำหน้าที่เชื่อมสองทาง — โหลดข้อมูลของรายการที่เลือกเข้า store
และส่งทุกการแก้ไขใน store กลับขึ้นไปเป็นข้อมูลรายการ จึงร่างได้ทีละรายการตามหน้าจอ

หน้ารายงาน (`renderSheet`) และสถานะในสารบัญ (`overallOf`) คำนวณจากข้อมูลของรายการล้วน ๆ
ไม่พึ่ง store จึงพิมพ์ทั้งเล่มพร้อมกันได้
